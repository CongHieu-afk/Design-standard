# Bản đồ tài liệu

Agent không đọc toàn bộ `design_standard/`. Chỉ mở phần đúng việc:

| Việc | Đọc |
| --- | --- |
| Phân loại làn, cổng, thứ tự làm | `01_QUY_TRINH.md`, `02_PHAN_CAP.md` |
| Loại trang, trạng thái, nền tảng | `03_LOAI_TRANG.md`, `03B_NEN_TANG_THIET_BI.md` |
| Token, màu, chữ, nền tảng UI | `04_NEN_TANG.md`, `05_NGON_NGU.md` |
| Motion/3D | `06_CHUYEN_DONG_3D.md` |
| Chống AI slop và hướng thị giác | `07_CHONG_AI_SLOP.md` |
| Nghiệm thu và severity | `08_NGHIEM_THU.md` |
| Lệnh, CI, MCP | `09_CONG_CU.md`, `12_BAN_DO_CONG_CU.md` |
| Mẫu artifact | `10_MAU.md` |
| Đánh giá/cải thiện giao diện có sẵn | `11_DANH_GIA_VA_CAI_THIEN.md` |

`CHANGELOG.md`, tài liệu phân tích và phụ lục là lịch sử/tham khảo; không phải policy agent phải nạp đầu phiên.
